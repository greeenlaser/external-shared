# Lua

Version: 5.5.1

This project was built with [KalaMake](https://github.com/kalakit/kalamake). Use the `.kmake` file and the kalamake CLI to compile [lua](https://github.com/lua/lua) from source.

When compiling this library from scratch:
- Copy all .c files to `src` and all .h files to `include`.
