# miniaudio

Version: 0.11.25

This project was built with [KalaMake](https://github.com/kalakit/kalamake). Use the `.kmake` file with the kalamake CLI to compile [miniaudio](https://github.com/mackron/miniaudio) from source.

When compiling this library from scratch:
- Copy `miniaudio.c` to `src` and `miniaudio.h` to `include`
